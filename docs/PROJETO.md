# PROJETO

# Nome

Portfólio Pessoal — Matheus Batista

---

# Objetivo

Criar um portfólio premium que transmita profissionalismo, sofisticação e autoridade.

O objetivo NÃO é criar um currículo online.

O objetivo NÃO é criar um template comum.

O site deve transmitir a sensação de um estúdio digital especializado em desenvolvimento de sistemas web.

---

# Público-alvo

- Empresas
- Startups
- Pequenos e médios negócios
- Clientes que valorizam qualidade
- Clientes que buscam soluções personalizadas

---

# Posicionamento

Quero que o visitante tenha a sensação de estar entrando no site de um pequeno estúdio digital moderno.

A comunicação deve transmitir:

- confiança
- organização
- qualidade
- simplicidade
- atenção aos detalhes

Nunca parecer exagerado.

Nunca parecer futurista.

Nunca parecer "gamer".

# Objetivos do usuário

O visitante deve conseguir:

- conhecer meu trabalho
- visualizar meus projetos
- entender minha forma de trabalhar
- entrar em contato rapidamente

---

# Sensação desejada

O usuário deve pensar:

"Esse desenvolvedor parece extremamente organizado."

"Esse projeto transmite confiança."

"Esse site parece ter sido feito por um estúdio."

---

# Regras

Sempre pensar primeiro em experiência do usuário.

Nunca adicionar elementos apenas por estética.

Toda animação deve possuir uma função.

Todo componente deve possuir um motivo para existir.

Qualidade acima de quantidade.
