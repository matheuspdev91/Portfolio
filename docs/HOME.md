# HOME

## Objetivo

A Home deve causar uma excelente primeira impressão.

Em menos de 5 segundos o visitante deve entender:

- quem sou;
- o que faço;
- meu nível técnico;
- como entrar em contato.

---

# Estrutura

1. Hero

2. Sobre

3. Projetos

4. Stack

5. Processo

6. CTA

7. Footer

---

# Hero

Objetivo

Criar impacto visual.

Nunca utilizar imagem de banco.

Priorizar tipografia.

Possuir CTA.

Possuir indicador de disponibilidade.

---

# Sobre

Objetivo

Apresentar rapidamente quem sou.

Texto curto.

Muito espaço.

---

# Projetos

Mostrar apenas os principais.

Cada card deve conter:

- imagem
- descrição
- stack
- tecnologias

---

# Motion

Fade

Reveal

Microinterações

Nunca exagerar.

---

# Mobile

Prioridade total.

A experiência mobile deve ser tão boa quanto a desktop.
