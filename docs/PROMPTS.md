# PROMPTS

Este documento reúne os prompts oficiais utilizados no projeto.

Sempre reutilizar estes prompts antes de criar novos.

---

# DIREÇÃO DE ARTE

## Objetivo

Criar conceitos visuais.

### Prompt

Quero que você atue como Diretor de Arte e UI/UX Designer.

Antes de pensar em código, pense como um estúdio de design.

Analise o contexto do projeto, o DESIGN_SYSTEM.md, o IDENTIDADE.md e o PROJETO.md.

Crie propostas de layout que transmitam sofisticação, simplicidade e organização.

Nunca copie referências.

Extraia apenas os princípios de design.

---

# WIREFRAME

## Objetivo

Criar estrutura da página.

### Prompt

Crie um wireframe detalhado.

Não escreva código.

Mostre apenas a estrutura.

Descreva:

- grids
- alinhamentos
- hierarquia
- espaçamentos
- fluxo de leitura
- comportamento do scroll

---

# IMPLEMENTAÇÃO

## Objetivo

Transformar o wireframe em código.

### Prompt

Implemente apenas a seção solicitada.

Tecnologias:

- Django
- HTML
- CSS
- JavaScript

Nunca utilize:

- Bootstrap
- Tailwind
- React
- Vue

Antes de escrever código explique as decisões tomadas.

# REVISÃO

## Objetivo

Encontrar melhorias.

### Prompt

Analise esta página como um UX Designer Sênior.

Avalie:

- hierarquia visual
- contraste
- responsividade
- acessibilidade
- performance
- consistência
- experiência do usuário

Liste apenas melhorias realmente relevantes.

---

# RESPONSIVIDADE

## Objetivo

Melhorar mobile.

### Prompt

Analise exclusivamente a versão mobile.

Não altere desktop.

Priorize:

- espaçamento
- tipografia
- alinhamento
- usabilidade
- área de toque
- performance

---

# REFATORAÇÃO

## Objetivo

Melhorar código existente.

### Prompt

Refatore apenas o código necessário.

Nunca altere comportamento visual sem autorização.

Priorize:

- organização
- reutilização
- legibilidade
- performance

Explique todas as alterações realizadas.

# ANIMAÇÕES

## Objetivo

Criar motion.

### Prompt

Crie animações discretas.

Priorize:

- fade
- slide
- reveal
- microinterações

Evite:

- bounce
- glitch
- neon piscando
- exageros

A animação deve reforçar a experiência e nunca chamar mais atenção que o conteúdo.
